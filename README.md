# kronos-edge

Financial K-line foundation model edge runtime.

Upgraded from [shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos).

## Features
- Tokenizer + predictor interface
- Live-data adapter (CCXT/Binance ready)
- Backtest harness
- Paper-trading mode

```bash
pip install -r requirements.txt
python -m kronos_edge
```
